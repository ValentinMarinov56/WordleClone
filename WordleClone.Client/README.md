# WordleClone Client

The WordleClone browser app is built with React, JavaScript, and Vite.

## Development

From this directory, install dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

The development server runs at `http://localhost:5173` and proxies `/api` requests to the local API at `http://localhost:5101`.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build in `dist/`
- `npm run preview` — preview the production build
- `npm run lint` — run Oxlint

For complete API, database, and Docker setup instructions, see the [repository README](../README.md).
